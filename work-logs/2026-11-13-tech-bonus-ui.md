# 作業ログ 2026-11-13: 加点になる投げ方・受け方がわかるUI

- 日付: 2026-11-13
- 実施者: 手動（オーナー指示「加点になる投げ方とならない投げ方がわかるUIにしたい」）
- 対象issue: なし

## 調べたこと

- 投げ・受けのチェックは見た目が同じで、視野外・手以外・手具を使った（+0.1）と、横投げ・無回転（加点なし、種類だけ）、
  必須投げ（左手投げ・二つ投げ）の区別が画面から分からなかった。
- 技術加点の重複判定（全く同じ投げ方・受け方は2回目以降0）を入れたので、「チェックは加点になるが、この投げでは加点されていない」
  という状態も起きる。静的な目印だけでは足りないので、投げ・受けごとの実際の結果も出すことにした。

## やったこと

- `constants.ts`：`techOptionKind(id)`（bonus／kind）。採点の `bonusThrowTypes` と同じ分け方。
- `score.ts`：`SeriesBreakdown.techItems`（アイテムごとの `TechStatus`：earned／none／duplicate／dupSeries／over と点数）。
  技術加点の計算をこの配列から出すようにまとめた（合計 `tech` と一致）。
- `SeriesCard.tsx`：チェックの横に `OptionBadge`（+0.1／種類／必須）、投げ・キャッチの見出しの下に `TechStatusLine`
  （「技術加点 +0.1」「技術加点なし：全く同じ受け方は加点済み」など）。技の最中の投げ・受けにも出す。視野外の方向にも「種類」。
- `index.css`：`.opt-badge`（is-bonus／is-kind／is-req）と `.tech-status`（is-earned／is-lost）。
- テスト：`techStatus.test.ts`。

## 確認

- `npm test`（1066件）・`npm run build` 緑。
- `vite preview` を Playwright で開き、クラブで「背面投げ→シェネ3→手具を使ったキャッチ」「背面の横投げ→前転→手具を使ったキャッチ」の
  2本目のカードを撮って確認：投げは横で別の投げ方なので +0.1、キャッチは加点済みと赤字で出る。
