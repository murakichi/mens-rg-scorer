# 作業ログ 2026-10-02: 生成：タンブリング中の投げは上級者だけにする

- 日付: 2026-10-02
- 実施者: 手動（オーナー依頼）
- 対象issue: なし（依頼「投げタン実施時、タンブ中の投げを行うのは上級者のみです。通常の投げより頻度は低くなっている？」）

## 調べたこと

- 答えは**なっていなかった**。`throwInSkill` には形そのものの重みも要求値のゲートも無く、
  投げタン4形のうち2形（`chainThrowInSkill` / `connectThrowInSkill`）がそれだった
- 候補の内訳はほぼ半々（スティックの投げタン18本中 技の最中8／先に投げ10）。
  ところが**生成結果では上級者側の多数派**だった（各20構成）:

  | 上限 | 技の最中に投げ | 先に投げ |
  | --- | --- | --- |
  | 1.5 | 0 | 20 |
  | 2.0 | 5〜8 | 12〜15 |
  | 2.5 | 3 | 17 |
  | 3.0 | 11 | 9 |
  | 3.5 | 13〜14 | 6〜7 |
  | 4.5 / 上限なし | 12〜13 | 7〜8 |

- 増幅の理由：`chainThrowInSkill` は**三宙と投げタンを1本のシリーズで両立**してシリーズを
  1本節約するので、貪欲法が必ず拾う。「頻度は2か所で決まる」のいつもの形
- 問題は2つ：①上級者限定になっていない（上限2.0で25〜40%出る）
  ②上級者でも通常の投げタンより多い（55〜70%）

## やったこと

- `src/scoring/tumblingWeights.ts`: `THROW_IN_SKILL_MIN_SCORE`（**4.0**）/
  `THROW_IN_SKILL_CHANCE`（0.4）/ `throwInSkillChance(targetScore)` を追加
- `src/scoring/autoTumblings.ts`: `autoTumblingSpecs` で**生成ごとに1回だけ抽選**し、
  外れたら `throwInSkill` の形を候補に入れない（`rarityChance` を通すので珍しさのつまみも効く）。
  形ごとに引かないのは `verticalThreeChance` と同じ理由 — 生き残りを貪欲法が拾ってしまう
- `src/scoring/__tests__/autoTumblings.test.ts`: 新規テスト1本。既存の
  「連続の最後に投げる形は普通のタンブリングと同じ入り方ができる」は1つの種に頼っていたので
  複数の種を回すように直した

## 確認

- `npm test`: 745本すべて green
- `npm run build`: green
- 実測（直した後。4手具 各20構成）：**上限3.5以下は 0**、上限4.0以上で技の最中が 2〜6 に対し
  先に投げが 14〜18。要望どおり「上級者だけ・通常の投げタンより少ない」になった。
  しきい値は最初 3.0 で測ってオーナーに提示し、**「D要求値4以上で実施」との指定**を受けて 4.0 にした
  （代償は同じ：未達 0.00〜0.10 → 0.00〜0.20、D は変わらず。境目は実測ではなくドメインの判断）
- **代償**（ゲート無しと同条件で比較、4手具 × 4条件 × 20構成）：
  未達の必須要素が 0.00〜0.05 → 0.00〜0.10（上限3.0〜3.5 で三宙かつなぎが20構成中1〜2本）、
  Dスコアが約 −0.05。シリーズを1本節約する形を減らすので
  「三宙＋つなぎ＋投げタンを3本に収める」きつい場合に寄るため。小さいので受け入れた

## 気づき・申し送り

- **テストの疑似乱数（`seeded`）は最初の出力が種にほぼ比例する**（種3→0.54、7→0.60、
  11→0.65…）。最初の `rand()` を消費する抽選は、小さい奇数の種では必ず外れる。
  既存テストが1本落ちたのはこれが原因で、生成器のバグではない。
  当たる種（偶数の小さいもの）と外れる種の両方を踏むテストにした。
  同じ罠は `autoThrowSpecs` の `keepVerticalThree` にもあるので、
  今後この位置に抽選を足すときは注意する
- `chainThrowInSkill` を減らすと必須要素がわずかに落ちるのは、
  「三宙＋つなぎ＋投げタンを3本のシリーズに収める」のが本質的にきついため。
  `DEFAULT_MAX_TUMBLINGS`（3 ＝ `ADOPT_COUNT`）を動かす話になるので今回は触っていない
