# 2026-11-20 高難度を含むタンブリングを前に（優先）

## 依頼
- 単発で高難度が含まれるシリーズのタンブリングは、そうでないタンブリングより前での実施を優先。投げタンで技の最中に投げる場合はその限りではない。あくまで優先、絶対ではない。

## 変更
- `highDifficultyTumblingFirst`（`generateSearch.ts`、`orderSeries` の最後）：投げを含まないタンブリングのシリーズが並ぶ位置の中で、D以上の技を含むものを前に寄せる。投げ・投げタンの位置は動かさない（ほかの投げタンは3〜4つ目に置く決まりが先にあるため）。
- 8割（`HIGH_TUMBLING_FIRST_CHANCE`）でだけ並べ替える。決め方は乱数ではなく中身のハッシュ（乱数を引くとほかの抽選がずれるため）。

## 結果
- 120構成（4手具×上限3.0／4.5／なし×10）で、高難度とそうでないタンブリングが混ざる34構成のうち、低難度が先にあるもの 21→5。
- `npm run quality`：全指標が基準値と同じ（並びは点数に関係しない）。

## 判断
- 3〜4つ目に置く投げタン（技の最中に投げない形）は、高難度を含んでも今回の並べ替えでは動かさなかった。投げタンの位置の決まりと、どちらを優先するかはオーナーに確認していない。
