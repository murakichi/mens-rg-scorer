# 作業ログ 2026-09-18: 技ごとの出やすさのモーダルが生成モーダルの後ろに出る

- 日付: 2026-09-18
- 実施者: 手動（オーナーからの報告）
- 対象issue: なし（不具合報告を直接修正）

## 調べたこと

- 報告：「技ごとの出やすさのモーダルがランダム生成のモーダルの後ろに出て操作できない」。再現した。
- `src/index.css:842` の `.modal-overlay` は `z-index: 1000` の1種類しかない。
  生成モーダルも技ごとの重みモーダルも同じクラスなので **同じ重なり順**になり、
  後は DOM の順で決まる。
- `GenerateModal.tsx` は `<SkillWeightModal />` を生成モーダルの **前** に置いていたので、
  常に生成モーダル側が上に描画されていた（背後のモーダルはクリックも届かない）。

## やったこと

- `src/index.css`: `.modal-overlay.is-nested`（`z-index: 1100`）を追加。
  「モーダルの中から開くモーダルは前に出す」という意図をクラス名で残した。
- `src/components/SkillWeightModal.tsx`: overlay を `modal-overlay is-nested` に。
- `src/components/GenerateModal.tsx`: `<SkillWeightModal />` を生成モーダルの **後** に移した。
  z-index だけでも直るが、DOM の順も描画の順に合わせておく（片方を消しても戻らないように）。

## 確認

- `npm test`: 613 passed (17 files)
- `npm run build`: 成功
- 手で確認：生成モーダル →「技ごとの出やすさ」で重みモーダルが前に出て、
  スライダー・行ごとの戻す・まとめて戻すが操作できる。閉じると生成モーダルに戻る。
  重みモーダルの背景をクリックしても生成モーダルは閉じない（別要素なのでイベントは伝播しない）。
