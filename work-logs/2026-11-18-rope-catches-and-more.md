# 2026-11-18 ロープの足に巻き付け／投げタンの足キャッチ／連続投げ2回目の視野外キャッチ／ロープの手以外・視野外／前転3回と横向き／リングの横投げ前提の表示／ロンダートで受け

## 依頼（オーナー）
1. ロープの足に巻き付けたキャッチは最後のシリーズのみ。前転や転がりからは基本的に実施しない（難度にどうしても必要なら可、基本はそうならないように生成）。
2. 転がりからの肩キャッチも基本的に生成しない。
3. 投げタンで足キャッチはレア。
4. 連続投げの2回目で視野外キャッチは通常キャッチより少なめ。
5. ロープの手以外キャッチ、視野外キャッチはほかの種目より少なめ。
6. 視野外かつ横向きの投げでは前転3回を実施しない。
7. リングの受け方の「（横投げ前提）」の表記は要らない。横投げのときだけ選択肢に出す。
8. 投げ→ロンダートで受けはリングでのみ生成。

## 変更
- 評価：`ropeFootWrapIssues`（最後以外の足に巻き付け・前転/転がり直後の足に巻き付け・転がり直後の肩・締め以外の手以外/視野外キャッチ）。ロープの締めは足に巻き付けだけを締めとみなし、重みを 0.3 にした。
- 受け方：`withNonHandKinds` でロープは前転・転がりの直後は肩、シリーズの最後の受けは足に巻き付け、途中は肩。投げタンは足の受け方を8本に1本だけ残す。並べたあと `arrangeRopeFootWrap` が最後以外を肩に直し、最後のシリーズの締めを足に巻き付けにする（通常キャッチの締めも評価が上がれば足に巻き付けにする）。
- 連続投げ：`noViewPair` の2回目は4割だけ視野外で受ける（出現順で配る）。`trailPair` の受けは視野外の重み 0.5。
- ロープの手以外・視野外：引きの重み 0.5、評価 0.2/1つ、投げタンの手以外の確率 0.3→0.15。
- `maybeSideThrow` の `verticalThree`：前転3回の投げは視野外でも横にしない。
- エディタ：リングの横投げ前提の受け方は `sideThrowCatchFlags` が true のときだけ出す（選択済みは残す）。表示名から「（横投げ前提）」を外した。
- `CATCH_IN_ROUNDOFF_APPARATUS`＝ring。

## 試してだめだったこと
- 連続投げの2回目の受けを乱数で引いたところ、ほかの抽選がずれてクラブの「下限4.2で全部E」が 42/50→31/50 に下がった（効果を消して乱数だけ引いても 34/50）。出現順で配る形にした。
- ロープの視野外キャッチは評価の重みを 0〜0.3 に振っても 0.58〜0.69/構成にとどまる。受け方の種類（A側）を満たすのに使われていて、これ以上は重みでは減らない。

## 残り
- ロープの視野外キャッチがほかの手具並み（リング 0.51、クラブ 0.73、ロープ 0.96）。減らすなら受け方の種類の満たし方（ロープは手具を使ったキャッチが無い）から見直す必要がある。
- ロープのD平均 3.98→3.94。
- リングの投げタンで足以外の受け方が無い形（横投げでない＝上半身に入れるが出せない）は足で受けることがある（45構成で2回）。
