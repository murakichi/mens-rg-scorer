# 2026-11-20 後方系→テンポ→後方系からの4本目／後方の伸身系で終わらない

## 依頼
- 三宙で後方系の宙返り→テンポ→後方系の宙返りを実施した場合、そこから4本目の宙返りを実施してもよい。4本目は前方系が多い。
- パターンを問わず、上級者がシリーズの最後を後方の伸身系でそのまま終わることは滅多にない。

## 変更
- `hasBackTempoBack`（autoTumblings）：つなぎ技をまたがない「後方系→テンポ→後方系」を見つける。宙返りで終えるタンブリングの形では、これを含むとき `saltos.max` を1本超えて遷移表を進める。4本目は遷移表どおり（後ろ向きに降りる後方系のあとは前方系・側方系）。
- `endRule`（tumblingTransitions）：後方の伸身系（`isBackLayoutSalto`）で終わるのを、稀な終わり方の抽選（`RARE_CHAIN_END_CHANCE` 0.1）を通したときだけにした。基本的な構成は抽選なしで終われる。投げタンは最後がキャッチなので `chainEndsOk` で対象外にした。

## 結果
- `docs/generator-notes.md` のとおり。4本目は上限4.5以上で 0→11〜12本（120構成）、すべて前方系・側方系。後方の伸身系で終わるのは 4→2。
- `npm run quality` は許容幅の内（スティックの全部Eは戻った）。

## 試してだめだったこと
- 最初は投げタンにも4本目と終わり方の決まりを掛けていて、「側宙の実施中に投げる構成は稀」が落ちた。投げタンを外しても落ちたので調べたら、比率は変わっておらず（0.32→0.33）、テストのしきい値が実測値ちょうどだった。100種・0.4未満に直した。

## 残り
- 4本目に後方系（後方宙返り1回半ひねり）が出ることもある（下限なしで1回）。前方系が「多い」の範囲として残した。
