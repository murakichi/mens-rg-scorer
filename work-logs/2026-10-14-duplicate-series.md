## セルフレビュー（`/code-review high`）

2件。1件は直し、1件は**既存の不具合だったので別 issue にした**。

1. **シリーズを増やせない画面にも複製ボタンが出ていた** — シリーズテンプレートの編集と
   レーティング入力は先頭1本しか受け取らない（`TemplateModal` の `toSeries: (s) => s[0]`、
   `RatingScreen` の `patch(curIdx, { series: next[0] ?? … })`）ので、押しても何も起きず、
   テンプレートの `updatedAt` だけ黙って動く。`allowAdd`（「シリーズを追加」を出すかの判定）で
   同じように隠した。
2. **途中に挿すとカードのローカル状態がずれる** → **#150 を起票して、このPRでは直していない。**
   `<SeriesCard key={sIdx}>` と添字をキーにしているため。**既存の不具合であることを実測で確認した**:
   `origin/main` の本番ビルドで「3本目を畳む→1本目を削除」すると `[開,開,畳]` → `[開,開]` となり、
   畳みが繰り上がらずに消える。複製でも同じ（`[開,開,畳]` → `[開,開,畳,開]`、期待は `[開,開,開,畳]`）。
   採点には影響しないが、新しく作ったシリーズが隣の「畳み」や「手動入力」の状態を引き継いで見える。
   直すにはシリーズに安定した識別子が要り、保存形式に関わる判断なので #69 の範囲を超える。

修正後: `npm test` 948件 green、`npm run build` green、E2E 7項目 PASS。
