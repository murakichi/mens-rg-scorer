# work-logs — 作業ログ

**このリポジトリでの作業は、1回につき1本ここにログを残す。** ループで回すスキルだけでなく、
普段の作業（機能追加、バグ修正、リファクタ、調査だけで終わった回も）すべてが対象。
目的は「何をしたか」の記録ではなく、**次の人（次のエージェント）が同じ調査を繰り返さずに済むこと**。

- ファイル名: `YYYY-MM-DD-<slug>.md`（同じ日に複数あれば `-2`, `-3` と続ける）
- テンプレ: `_TEMPLATE.md`
- コミット: 変更と **同じコミット / 同じ PR** に含める（あとでまとめて書かない）
- 採点ロジックのルール準拠テスト（`scoring-test`）は `test-reports/` 側に書くので、
  こちらには重複して書かない（work-logs から `test-reports/NNN-....md` を参照するだけでよい）

ログは短くてよい。**判断の根拠**（ルールのどこ / コードのどこを見て、なぜそう決めたか）と、
**試して駄目だったこと**、**やり残し** が書いてあれば十分。成功した手順の清書は要らない。
