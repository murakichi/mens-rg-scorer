# 2026-11-20 視野外の受け→連続投げを生成から外す

## 依頼
- 視野外の受け→連続投げは現実的ではないので、自動生成から外す。

## 変更
- `NO_THROW_AFTER_CATCH_TAGS` に `noview` を追加（手以外・手具を使ったキャッチと同じく、そのあと投げない）。
- テスト：既存の「視野外のあとは視野外以外なら投げられる」を逆の内容に直し、候補に視野外キャッチ→投げが無いことを `rules20261118.test.ts` に追加。

## 結果・判断
- 候補で 365→0、生成した構成で 2/32→0。
- `npm run quality` でスティックの下限4.2が悪化（E不足 0.30→0.45、120構成で 0.33→0.43／全部E 72%→62%）。新しい物差しが最初に拾った実際の悪化。オーナー指定の変更なので基準値を更新した。
- スティックの全部Eを取り戻すなら、視野外キャッチ以外で2回目の投げに続く高難度の形（通常キャッチ→背面投げ など）が足りているかを見る必要がある。
