# 作業ログ 2026-09-30: 投げ→シェネのあとのキャッチ候補

## やったこと

- `autoInput.ts`: 投げのあとにシェネ（合計1〜3回、`CHENE_CATCH_MAX_COUNT`）を入力した時点で、キャッチ／前転→キャッチ を候補に出す。すでにキャッチ1つだけの候補（ロープの手以外のキャッチ）があればそれが先頭。3回のときは従来の キャッチ→視野外投げ→視野外キャッチ も別案に残る。
- 横投げ（クラブ・リング）のキャッチ差し替えは既存どおり、これらの候補にも掛かる。

## 判断

- 「シェネの回数」は、投げてから入力したシェネの合計回数とした（シェネの項目を複数に分けても合算）。

## 確認

- `npm test` / `npm run typecheck` / `npm run build`

## 追記: 背面投げのおすすめの条件

- 投げ→徒手3動作以上のあとの キャッチ→視野外投げ→視野外キャッチ は、**ほかのシリーズに連続投げ（1シリーズに投げが2回以上）が無いとき**だけ出す（`hasConsecutiveThrowElsewhere`）。連続投げは構成に1回あれば十分という想定。
